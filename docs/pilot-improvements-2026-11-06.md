# 조종사 관점 개선·검증 범위 — 2026-11-06

## 배포 상태
- 기존 1.0.6(39) 아카이브는 이미지 가져오기·롤러 간격 수정까지만 포함한다. 이후 추가 요구가 있어 업로드하지 않았다.
- 현재 소스는 후속 변경 중이다. 최종 범위와 디자인 확인 후 새 아카이브를 만든다. 기존 39 아카이브를 업로드하지 않는다.
- 실제 무음/집중 모드 울림, 앱 강제 종료·재부팅 후 울림, Apple Watch 전달은 미검증이다.

## 완료한 원본 대조
- October 이미지 8편과 202610.ics의 편명·구간·날짜 일치. 2편의 시각은 원본끼리 다르다.
- October 이미지와 calendar-ical.ics의 8편 편명·구간·날짜 일치. 8편의 시각은 원본끼리 다르다.
- November 이미지 6편과 202611.ics의 편명·구간·출도착 날짜·시각 모두 일치.
- 이미지를 날짜 칸별로 확대 인식하고, 복사 텍스트의 공백·시간 구분자와 날짜 순서를 정규화했다.
- 10월 이미지의 DH678은 해당 한국항공사 로스터 문맥에서 KE678로 연결한다. 임의의 다른 항공사 로스터에는 일반화하지 않는다.
- 실제 iPhone Live Text가 모든 달력에서 동일한 읽기 순서를 보장하지 않는다. 날짜-내용 연결이 유실된 복사는 추정으로 저장하지 않고 원본 이미지 가져오기를 안내해야 한다.

## 현재 소스에 반영한 후속 변경 (아직 배포하지 않음)
- 원형 시계 시침을 24시간 기준으로 변경. 첫 알람 강조 유지.
- 헤더 높이를 76에서 64로 축소. Briefing/Roster의 + Add Roster 표현·위치 통일.
- Briefing 비행 선택 텍스트의 줄바꿈을 허용하고 과도한 제목 위 여백 축소.
- ICN과 Home 카드가 같은 시간대·시각이면 합침.
- 출발·도착 공항의 Local 기준을 공통 비행 정보 아래 표시. 시간대 카드 L/Z 표시.
- 준비 알람 오프셋 형식은 Briefing/Roster 모두 -4h30m으로 통일.
- 일반 알림/AlarmKit 권한을 별도 조회. 비활성 경고와 iPhone Settings 이동 버튼.
- Stop 기록 최근 100건을 기기에 보관하고 Settings에서 조회. 과거 기록 소급 불가.
- 공통 헤더·반응형 요약 관련 6개 테스트 통과. iOS 네이티브 변경은 최종 빌드 검증 필요.

## 확인이 필요한 제품 결정
1. 비행 준비는 출발 공항 기준 고정, 개인/체류지 알람은 홈 시각 유지 또는 기기 현지 시각을 선택하는 안.
2. UTC/Local 전환은 표시만 바꾸고 예약된 절대 시각은 바꾸지 않는 안.
3. 이번 TestFlight에 안정성/UI 수정까지 먼저 포함할지, 확장 기능 전체까지 기다릴지.
4. 신규 화면 시안: work/pilot-design-proposal-full.png. 실제 실행 화면이 아닌 제안이다.
